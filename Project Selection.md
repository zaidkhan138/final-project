# Project Selection

## Project Name

CampusBus - College Bus Reservation and Waiting List Management System

## Why This Project Was Selected

CampusBus was selected because it solves a real problem faced by college students who travel by college buses. During weekends and holidays, bus seats fill quickly and students do not always know whether a seat is available.

The project is suitable for a one-week web development submission because it uses simple technologies taught in the course:

- Python
- FastAPI
- SQLite
- Pydantic
- HTML
- CSS
- JavaScript
- Fetch API
- Jinja2
- JWT authentication

## Problem Statement

Students need a central system to:

- View available bus trips
- Check remaining seats
- Reserve seats
- Join a waiting list
- Cancel reservations
- View their booking history

Administrators need a system to:

- Manage buses
- Manage routes
- Create trips
- View bookings
- Handle waiting lists
- Manage extra-bus requests

## Scope of the Project

The project includes student registration, login, role-based access, bus and route management, trip listing, seat reservation, waiting-list management, cancellation, and extra-bus requests.

Payment, live GPS tracking, SMS, email, QR tickets, and mobile applications are not included.

## Target Users

- Students
- College administrators

## Main Technologies

- FastAPI for backend APIs
- SQLite for data storage
- Jinja2 for simple web pages
- JavaScript Fetch API for frontend-backend communication
- HTML and CSS for page structure and styling
- JWT for login authentication
